# 实验报告填写指南

正式报告自动生成在 `evaluation/<实验名称>/report.md`，这里说明如何阅读和补充。

1. 问题：将 CIFAR-10 的 32×32 彩色图像分类到 10 类。
2. 方法：ResNet18 输入层调整、无预训练、交叉熵、SGD 和数据增强。
3. 数据：45000 训练、5000 验证、10000 官方测试；测试不参与最佳模型选择。
4. 结果：填写真实测试准确率、最佳验证轮次和训练时间，引用自动生成的曲线和混淆矩阵。
5. 分析：训练与验证准确率差距是否扩大；哪些类别容易混淆；后续怎样改进。
6. 复现：提供代码、requirements、configs、样本划分索引和环境记录。

没有正式测试结果时写“尚未完成”，不要把 smoke 的小样本验证成绩写成最终成绩。
